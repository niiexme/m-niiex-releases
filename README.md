# m.niiex — сборки и обновления

Здесь только готовые сборки плеера m.niiex и подписанный файл обновлений (`latest.json`). Исходного кода тут нет.

- **Android:** `m.niiex-<версия>.apk` из последнего релиза.
- **Windows:** `m.niiex-<версия>-windows.zip` — распаковать и запустить `m.niiex.exe`.

Дальше приложение обновляется само: каждый файл подписан, чужие или повреждённые файлы оно не ставит.
